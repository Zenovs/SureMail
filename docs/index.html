Dein E-Mail-Client.
Schlank. Frei. Lokal.

CoreMail Desktop ist ein Open-Source-E-Mail-Client für Linux — IMAP/SMTP, Microsoft 365 via Graph API, 11 Themes, kein Tracking, keine Cloud.

v6.1.0 MIT License Linux x64 / arm64 Raspberry Pi 4/5
Empfohlen

Installation per Terminal

$ curl -sSL https://raw.githubusercontent.com/Zenovs/coremail/initial-code/install.sh | bash -s -- --x64

oder direkt herunterladen
x64 AppImage ca. 135 MB arm64 AppImage ca. 135 MB

Direkt-Download startet ohne Skript — danach: chmod +x & ausführen.

Alles was ein E-Mail-Client braucht.
Mehr nicht.

Klar strukturiert, ohne Ablenkung, ohne Cloud-Abhängigkeit.

Mehrere Konten

Beliebig viele IMAP/SMTP- und Microsoft 365-Konten parallel — alles in einer Oberfläche.

Microsoft 365 via Graph

OAuth2-Login direkt mit Microsoft Graph API. Kein App-Passwort, keine Drittanbieter-Tools.

Split-View & Inline-Antwort

Mailliste und Vorschau nebeneinander, alle Spalten verstellbar. Antworten ohne Seitenwechsel.

Lokaler Spam-Filter

Heuristische Erkennung von Werbung, Spam, Phishing & Schadanhängen — komplett offline.

HTML-Vorlagen

Newsletter, Angebot, formeller Brief — fertig formatiert, oder eigenes HTML einfügen.

Carbon Design System

Einheitliche, monochrome Icons (IBM Carbon) und IBM Plex Sans für maximale Lesbarkeit.

Übersetzung integriert

Mails mit einem Klick in deine Sprache übersetzen. Über frei konfigurierbaren Endpoint.

11 Themes

Dark, Light, Minimal, Glas, Retro, Foundations, Lollipop, Nerd, Indie und mehr.

Datenschutz ohne Kompromisse

CoreMail spricht ausschliesslich mit deinen eigenen E-Mail-Servern. Keine Telemetrie, keine Cloud-KI, kein Tracking.

  • Alle Daten lokal auf deinem Computer
  • Kontodaten AES-verschlüsselt gespeichert
  • Keine Telemetrie, kein Analytics
  • Quellcode vollständig öffentlich (MIT)
  • Keine externen KI- oder Cloud-Dienste
  • Funktioniert offline mit lokalem Cache
